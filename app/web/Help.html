Lấy dữ liệu xuất nhập khẩu, không cần SQL

Chọn tháng → đặt điều kiện → chọn cột → bấm Get the file. Vài phút sau có file Excel trong thư mục output.

Trang BulkEx gồm các phần

1Data – bảng Export / Import và các tháng
2Filters – điều kiện lọc: mã HS, nước, công ty…
3Result – nhận danh sách (Detail) hay bảng tổng hợp (Summary), chọn cột
5Your request – đặt tên, kiểm tra, gửi
4My presets – mẫu đã lưu
6Recent requests – trạng thái, mở file

Lần đầu tiên (chỉ làm 1 lần)

  1. Mở trang. Vào thư mục BulkEx trên OneDrive, nháy đúp BulkEx.html. Dùng Chrome hoặc Edge.
  2. Chỉ cho trang biết thư mục. Ở khung tím bên phải bấm Choose BulkEx folder → chọn thư mục BulkEx (thư mục có input và output bên trong) → bấm Allow / Cho phép.
    Đúng: khung hiện “✓ Requests go straight to the BulkEx folder”.
    Sai: báo “Pick the BulkEx folder…” → bạn đang chọn nhầm thư mục con, chọn lại thư mục cha.
  3. Gõ tên bạn vào ô Requested by. Trang nhớ tên này cho các lần sau.

6 bước mỗi lần lấy dữ liệu

  1. Data – bảng nào, tháng nào.
    • Export = tờ khai xuất khẩu · Import = tờ khai nhập khẩu · Export + Import = cả hai.
    • Bấm ô tháng để chọn (ô cam = đã chọn). Bấm số năm để chọn cả năm. Quick pick chọn nhanh 3 / 6 / 9 / 12 tháng gần nhất.
    • Ô tháng mờ = tháng đó chưa có dữ liệu.
  2. Filters – chỉ lấy dòng nào.
    • Bấm + Add condition → chọn trường (vd HS Code) → chọn cách so (xem bảng bên dưới) → gõ giá trị, nhấn Enter sau mỗi giá trị.
    • Có sẵn danh sách trong Excel? Copy cả cột rồi dán vào ô giá trị: mỗi ô thành một giá trị.
    • Một điều kiện có nhiều giá trị = dòng khớp bất kỳ giá trị nào (VN hoặc IN).
    • Chọn Export + Import thì mỗi bảng có tab bộ lọc riêng; nút Copy to … chép bộ lọc sang bảng kia.
    • Không thêm điều kiện nào = lấy hết mọi dòng của các tháng đã chọn.
  3. Result – nhận gì.
    • Tick Detail rows để có danh sách từng dòng hàng; tick Summary để có bảng tổng hợp; tick cả hai được. Khác nhau thế nào?
    • Detail: chọn cột bằng Essentials (bộ cột hay dùng), All columns, hoặc Add a column…. Trường đã dùng để lọc tự có trong file.
    • File luôn có thêm 2 cột đầu Year, Month: dòng đó thuộc tháng nào.
  4. My presets – lưu để dùng lại (không bắt buộc).
    • Save as new lưu cả yêu cầu (tháng, bộ lọc, cột) dưới một cái tên; lần sau chọn tên đó là có lại y nguyên.
    • Mẫu lưu trong trình duyệt trên máy bạn. Back up để giữ một bản, Restore để nạp lại hoặc chuyển sang máy khác.
  5. Your request – đặt tên và gửi.
    • Request name: tên dễ nhớ, vd Pharma 3002 sang Ấn Độ 2025. Bắt buộc.
    • Đọc câu tóm tắt màu trắng trong khung tím: đó chính là điều bạn đang xin. Thấy chữ or ở chỗ bạn muốn and → quay lại bước 2.
    • Bấm Check row count trước: chỉ đếm số dòng, không làm file. Số quá lớn hoặc bằng 0 → sửa bộ lọc.
    • Ổn rồi thì bấm Get the file.
  6. Recent requests – chờ và mở kết quả.
    • Trạng thái: sent, waiting for the runner (đã gửi) → running (đang chạy) → ready (xong) hoặc couldn't run (lỗi, có ghi lý do).
    • Thường 2–5 phút; yêu cầu nhiều năm, hàng trăm nghìn dòng có thể 10–15 phút.
    • Xong thì bấm Open file (hoặc Open CSV). File nằm trong thư mục output.
    • Tab Done / Failed tách việc xong và việc lỗi. Only mine / Show everyone: xem của riêng bạn hay cả nhóm.
    • Use again nạp lại yêu cầu cũ vào trang để sửa rồi gửi lại (chỉ có với yêu cầu gửi từ chính máy bạn).

“Keep rows that match all / any” – quan trọng nhất

all (nên dùng)

Dòng phải khớp tất cả điều kiện.
HS 3002 và gửi từ Ấn Độ → chỉ hàng 3002 từ Ấn Độ.

any (cẩn thận)

Khớp một điều kiện là đủ.
HS 3002 hoặc gửi từ Ấn Độ → mọi lô 3002 từ mọi nước cộng mọi lô hàng bất kỳ từ Ấn Độ.
Chọn “any” thường ra rất nhiều dòng, dễ chạy quá 15 phút và bị dừng. Trang hiện cảnh báo màu cam khi bạn chọn any.
Cần “hoặc” cho một phần thôi? Giữ all và dùng + Add group (either / or). Ví dụ: HS 3002 và nhóm (gửi từ IN hoặc gửi từ VN). Với ví dụ này còn đơn giản hơn: một điều kiện Shipped From Country Code · is · IN, VN.

Detail và Summary khác gì?

Detail rows = danh sách

  • Mỗi dòng trong file = một dòng hàng trên tờ khai.
  • Bạn chọn các cột muốn xem.
  • Có thể rất nhiều dòng.
  • Dùng khi cần soi chi tiết, lọc tiếp trong Excel.

Summary = bảng tổng hợp

  • Gom các dòng giống nhau thành một dòng, rồi đếm và cộng tổng.
  • Bạn chọn gom theo gì và cộng cột số nào.
  • Ít dòng, gọn.
  • Dùng khi cần trả lời nhanh “ai nhập nhiều nhất”, “nước nào lớn nhất”.

Summary có 3 ô

  1. One row for each – gom theo trường nào. Chọn Importer Name → mỗi nhà nhập khẩu một dòng. Chọn Importer Name + HS Code → mỗi cặp (nhà nhập khẩu, mã HS) một dòng. Thường 1–2 trường là đủ.
  2. Add up – cột số cần cộng tổng: Invoice Value, Quantity 1, Total Gross Weight… Cột Records (số dòng) luôn có sẵn.
  3. Keep only the top – chỉ giữ N dòng lớn nhất (nhiều Records nhất). Để trống = lấy hết.

Ví dụ: One row for each = Importer Name, Add up = Invoice Value, top 20 → sheet Summary:

Importer NameRecordsTotal Invoice Value
Công ty A3121,250,000
Công ty B205980,000
… 20 dòng
Summary dùng cùng tháng và cùng bộ lọc với Detail, và gộp tất cả các tháng đã chọn lại với nhau. Tick cả hai → một file Excel có cả sheet Detail và sheet Summary.
